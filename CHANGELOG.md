# Changelog

All notable changes to Centrio are documented in this file.

This is a **technical companion to the in-app changelog** shown in the "История изменений" (version history) popup (`#changelogPopup` in `index.html:571-905`). That in-app popup is the authoritative, always-up-to-date source of what shipped in each version — entries below are transcribed from it verbatim (in Russian, matching the source) and kept in [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format. When adding a new version to the in-app popup, add the matching entry here too.

The format is based on Keep a Changelog. This project does not currently follow strict Semantic Versioning (patch numbers are sometimes skipped or reused across build attempts), so version numbers should be read as chronological release identifiers rather than strict semver.

## [1.8.10]

- Исправлен баг: настройка «Запускать с системой» иногда молча не применялась (использовался сторонний пакет `auto-launch`, шеллящийся в `reg.exe` на Windows) — переведено на нативный Electron API (`app.setLoginItemSettings`), ошибки применения теперь показываются пользователю вместо тихого падения
- Исправлен корневой баг нестабильного подключения VPN: при быстром переподключении новый процесс `sing-box` иногда не успевал занять порт, освобождённый предыдущим (отключение не дожидалось реального завершения процесса) — теперь отключение ждёт фактического завершения процесса перед запуском нового
- Исправлен баг: сохранённая VPN-конфигурация могла молча стереться при обычном временном сбое автовосстановления после перезапуска приложения (например, при таймауте запуска) — теперь конфигурация стирается только при действительно нечитаемой/невалидной ссылке
- Исправлен баг: кнопка «Импортировать» в настройках VPN оставалась заблокированной после успешного подключения по новой ссылке
- Технические сообщения об ошибках VPN (например, внутреннее имя процесса `sing-box`) заменены на понятные пользователю формулировки на всех языках приложения

## [1.8.9]

- Исправлен баг: если подписка Pro оплачивалась на сайте, приложение (уже запущенное или открытое заново без повторного входа) могло долго не видеть новый статус — теперь актуальный план (`plan`/`planExpiresAt`) подтягивается с сервера автоматически при запуске приложения и при каждом возврате фокуса на окно, тем же паттерном, что уже используется для уведомлений (`renderer/app-notif-bind.js`)

## [1.8.8]

- Исправлен баг: клик по ссылке-приглашению MAX (`max://max.ru/join/<token>`) или Telegram (`tg://resolve?domain=...`) переключал на нужную вкладку, но вместо перехода к чату показывал постороннюю страницу-заглушку (публичный лендинг `max.ru`/`t.me`, отдельный origin от рабочего веб-клиента), после чего вкладка переставала реагировать — переход теперь делается same-origin способом внутри уже открытого и залогиненного клиента (`web.max.ru/join/<token>` через `loadURL`, `web.telegram.org/#@username` через хэш-навигацию), без ухода на другой сайт
- Исправлен баг: вкладка MAX могла бесконечно сама перезагружаться — обработчик `did-fail-load` реагировал на любую ошибку загрузки (включая падение под-ресурса) немедленным релоадом без бэкоффа; теперь реагирует только на ошибку главного фрейма и делает экспоненциальный бэкофф между попытками

## [1.8.7]

- Добавлена поддержка ссылок-приглашений MAX (`max://max.ru/join/<token>`) — работает по тому же принципу, что и Telegram-диплинки: клик переключает на уже открытую вкладку MAX и сразу загружает приглашение в ней, вместо перехода во внешний браузер
- Исправлен критический баг: только что добавленная вкладка мессенджера иногда оставалась пустой и никогда не загружалась (race condition — проверка `will-attach-webview` из 1.8.5 иногда срабатывала раньше, чем новая вкладка успевала сохраниться, и блокировала её)
- Диагностическое логирование обработки диплинков (`tg://`, `max://`) перенесено в постоянный лог-файл приложения — упрощает разбор будущих обращений о "ссылка не открывается"

## [1.8.6]

- Работает как по клику внутри мессенджеров Centrio (webview click interception), так и по клику в других приложениях/браузере — если Centrio выбран обработчиком `tg://` в системе (OS-level protocol registration via `app.setAsDefaultProtocolClient`)

## [1.8.5]
